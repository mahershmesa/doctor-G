# موقع عيادة طبيب الأسنان — Doctor G

موقع بورتفوليو كامل لطبيب أسنان باللغة العربية، متجاوب مع جميع الشاشات (موبايل، آيباد، لابتوب، شاشات كبيرة)، مع لوحة تحكم لتعديل كل المحتوى.

## المميزات

| الميزة | التفاصيل |
|---|---|
| **مجسم ثلاثي الأبعاد** | سن متحرك (Three.js) في الواجهة، يتفاعل مع حركة الماوس ويمكن تدويره باللمس/السحب، مع حلقات وجزيئات متحركة. يمكن إيقافه واستبداله بصورة من لوحة التحكم. |
| **عرض الأعمال (بورتفوليو)** | صور قبل/بعد مع شريط مقارنة، معرض صور، فيديوهات (رفع مباشر أو رابط YouTube)، وتصنيفات. |
| **الخدمات، آراء المرضى، الأسئلة الشائعة** | قابلة للإضافة والتعديل والحذف وإعادة الترتيب. |
| **حجز موعد عبر واتساب** | المريض يختار الخدمة والتاريخ والوقت وطريقة الدفع، فتُجهَّز رسالة واتساب جاهزة إلى رقم العيادة. الأوقات المحجوزة تُغلق تلقائيًا، وأيام العطلة لا يمكن الحجز فيها. كل الحجوزات تظهر في لوحة التحكم. |
| **دردشة مباشرة مدفوعة** | الدردشة مقفلة حتى الدفع: المريض يختار طريقة الدفع ويرفق صورة الإيصال، ثم يوافق الطبيب أو المساعد من لوحة التحكم فتُفتح المحادثة فورًا (مباشرة، مع إرسال صور). |
| **لوحة تحكم** | تعديل كل النصوص والصور والفيديوهات والألوان وأرقام التواصل وطرق الدفع وأوقات العمل. إشعارات صوتية ومتصفح عند وصول حجز أو رسالة. |
| **صلاحيات** | حساب **الطبيب** (كامل الصلاحيات) وحسابات **مساعد** (الحجوزات والمحادثات فقط). |

## التشغيل محليًا

يتطلب [Node.js](https://nodejs.org) الإصدار 18 أو أحدث.

```bash
npm install
npm start
```

- الموقع: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin
- الدخول الأول: اسم المستخدم `admin` وكلمة المرور `admin123` — **غيّرها فورًا** من صفحة «كلمة المرور».

## أول خطوات بعد التشغيل

1. ادخل إلى لوحة التحكم ← **النصوص والإعدادات** ← **التواصل والدفع** وضع رقم واتساب العيادة بالصيغة الدولية (مثال: `9647701234567`). هذا الرقم هو الذي تصله الحجوزات.
2. من **طرق الدفع** أضف طرق الدفع وأرقام المحافظ/الحسابات.
3. من **الدردشة المدفوعة** حدد رسوم الاستشارة أو أوقف الدردشة.
4. أضف صورتك، الخدمات، والأعمال (صور قبل/بعد وفيديوهات).
5. من **المستخدمون** أنشئ حسابًا للمساعد.

## إعدادات اختيارية (متغيرات البيئة)

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ التشغيل (الافتراضي 3000) |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | بيانات حساب الطبيب عند أول تشغيل |
| `SESSION_SECRET` | مفتاح توقيع جلسات الدخول (يُنشأ تلقائيًا إن لم يُحدد) |
| `DATA_DIR` | مجلد قاعدة البيانات وإيصالات الدفع (الافتراضي `data/`) |
| `UPLOAD_DIR` | مجلد الصور والفيديوهات المرفوعة (الافتراضي `uploads/`) |
| `MAX_VIDEO_MB` | الحد الأقصى لحجم الفيديو (الافتراضي 200) |

## النشر على الإنترنت

الموقع يحتاج خادم Node.js (وليس استضافة صفحات ثابتة فقط) لأن فيه حجوزات ودردشة مباشرة ورفع ملفات.

- **VPS** (مثل Hetzner أو DigitalOcean): `npm install && npm start` خلف Nginx مع HTTPS، ويُفضّل تشغيله عبر `pm2`.
- **Docker**:
  ```bash
  docker build -t doctor-g .
  docker run -d -p 3000:3000 -v doctor-g-data:/data -e ADMIN_PASSWORD=كلمة-قوية doctor-g
  ```
- **Render / Railway / Fly.io**: يجب إضافة **قرص دائم (Persistent Disk)** وتوجيه `DATA_DIR` و`UPLOAD_DIR` إليه، وإلا ستُحذف الحجوزات والصور عند كل إعادة تشغيل.

> النسخ الاحتياطي: كل البيانات موجودة في مجلدي `data/` و`uploads/` — انسخهما دوريًا.

