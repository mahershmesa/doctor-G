# موقع عيادة د. نور علي لطب الأسنان — Dr. Noor Ali

موقع بورتفوليو كامل لطبيبة أسنان باللغة العربية، متجاوب مع جميع الشاشات (موبايل، آيباد، لابتوب، شاشات كبيرة)، مع لوحة تحكم لتعديل كل المحتوى.

## المميزات

| الميزة | التفاصيل |
|---|---|
| **مجسم ثلاثي الأبعاد** | سن متحرك (Three.js) في الواجهة، يتفاعل مع حركة الماوس ويمكن تدويره باللمس/السحب، مع حلقات وجزيئات متحركة. يمكن إيقافه واستبداله بصورة من لوحة التحكم. |
| **عرض الأعمال (بورتفوليو)** | صور قبل/بعد مع شريط مقارنة، معرض صور، فيديوهات (رفع مباشر أو رابط YouTube)، وتصنيفات. |
| **الخدمات، آراء المرضى، الأسئلة الشائعة** | قابلة للإضافة والتعديل والحذف وإعادة الترتيب. |
| **حجز موعد عبر واتساب** | المريض يختار الخدمة والتاريخ والوقت وطريقة الدفع، فتُجهَّز رسالة واتساب جاهزة إلى رقم العيادة. الأوقات المحجوزة تُغلق تلقائيًا، وأيام العطلة لا يمكن الحجز فيها. كل الحجوزات تظهر في لوحة التحكم. |
| **دردشة مباشرة مدفوعة** | الدردشة مقفلة حتى الدفع: المريض يختار طريقة الدفع ويرفق صورة الإيصال، ثم توافق الطبيبة أو المساعد من لوحة التحكم فتُفتح المحادثة فورًا (مباشرة، مع إرسال صور). |
| **لوحة تحكم** | تعديل كل النصوص والصور والفيديوهات والألوان وأرقام التواصل وطرق الدفع وأوقات العمل. إشعارات صوتية ومتصفح عند وصول حجز أو رسالة. |
| **ثلاث لغات** | العربية والإنجليزية والألمانية: قائمة لاختيار اللغة، والمحتوى يُترجم من لوحة التحكم (تبويب «لغة المحتوى»). الإنجليزية والألمانية تُعرض من اليسار لليمين تلقائيًا. |
| **سياسة الخصوصية** | صفحة `/privacy` بثلاث لغات، قابلة للتعديل من «النصوص والإعدادات ← سياسة الخصوصية». |
| **نسخ احتياطي يومي** | نسخة تلقائية كل يوم (آخر 14 يومًا) + تنزيل نسخة كاملة مع الصور والفيديو من صفحة «النسخ الاحتياطي». |
| **استعادة كلمة المرور** | رمز استعادة يظهر عند تعيين كلمة المرور، والطبيبة تعيّن كلمة مؤقتة للمساعد، وطريقة طوارئ لمدير الاستضافة (بالأسفل). |
| **صلاحيات** | حساب **الطبيبة** (كامل الصلاحيات) وحسابات **مساعد** (الحجوزات والمحادثات فقط). |

## التشغيل محليًا

يتطلب [Node.js](https://nodejs.org) الإصدار 18 أو أحدث.

```bash
npm install
npm start
```

- الموقع: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin
- الدخول الأول: اسم المستخدم `admin` وكلمة المرور `admin123` — **غيّرها فورًا** من صفحة «كلمة المرور».

## أول خطوات بعد التشغيل

1. ادخل إلى لوحة التحكم ← **النصوص والإعدادات** ← **التواصل والدفع** وضع رقم واتساب العيادة بالصيغة الدولية (مثال: `9647701234567`). هذا الرقم هو الذي تصله الحجوزات.
2. من **طرق الدفع** أضف طرق الدفع وأرقام المحافظ/الحسابات.
3. من **الدردشة المدفوعة** حدد رسوم الاستشارة أو أوقف الدردشة.
4. أضف صورتك، الخدمات، والأعمال (صور قبل/بعد وفيديوهات).
5. من **المستخدمون** أنشئ حسابًا للمساعد.

## إعدادات اختيارية (متغيرات البيئة)

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ التشغيل (الافتراضي 3000) |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | بيانات حساب الطبيبة عند أول تشغيل |
| `SESSION_SECRET` | مفتاح توقيع جلسات الدخول (يُنشأ تلقائيًا إن لم يُحدد) |
| `DATA_DIR` | مجلد قاعدة البيانات وإيصالات الدفع (الافتراضي `data/`) |
| `UPLOAD_DIR` | مجلد الصور والفيديوهات المرفوعة (الافتراضي `uploads/`) |
| `MAX_VIDEO_MB` | الحد الأقصى لحجم الفيديو (الافتراضي 200) |
| `ADMIN_RESET_PASSWORD` | **طوارئ:** إذا نسيت الطبيبة كلمة المرور ورمز الاستعادة، ضع هنا كلمة مؤقتة وأعد التشغيل. تُطبَّق مرة واحدة ويُطلب تغييرها عند الدخول. احذف المتغير بعدها |
| `BACKUP_DIR` / `BACKUP_KEEP_DAYS` | مجلد النسخ الاحتياطية (الافتراضي `data/backups`) وعدد الأيام المحفوظة (الافتراضي 14) |
| `TRUST_PROXY` | ضعه `1` فقط إذا كان الموقع خلف Nginx أو Render/Railway (لمعرفة عنوان الزائر الحقيقي). لا تضعه في غير ذلك |

## النشر على الإنترنت

### أسرع طريقة: Render بضغطة واحدة

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/mahershmesa/doctor-G)

سجّل الدخول بحساب GitHub، اكتب كلمة مرور لوحة التحكم في خانة `ADMIN_PASSWORD`، ثم اضغط **Apply**. الخطة المجانية مناسبة للتجربة فقط: الموقع ينام بعد 15 دقيقة بدون زيارات، والبيانات والصور تُمسح عند إعادة التشغيل.

### خيارات أخرى

الموقع يحتاج خادم Node.js (وليس استضافة صفحات ثابتة فقط) لأن فيه حجوزات ودردشة مباشرة ورفع ملفات.

- **VPS** (مثل Hetzner أو DigitalOcean): `npm install && npm start` خلف Nginx مع HTTPS، ويُفضّل تشغيله عبر `pm2`.
- **Docker**:
  ```bash
  docker build -t doctor-g .
  docker run -d -p 3000:3000 -v doctor-g-data:/data -e ADMIN_PASSWORD=كلمة-قوية doctor-g
  ```
- **Render / Railway / Fly.io**: يجب إضافة **قرص دائم (Persistent Disk)** وتوجيه `DATA_DIR` و`UPLOAD_DIR` إليه، وإلا ستُحذف الحجوزات والصور عند كل إعادة تشغيل.

> النسخ الاحتياطي: كل البيانات موجودة في مجلدي `data/` و`uploads/` — انسخهما دوريًا.

## بنية المشروع

```
server.js            الخادم: API، رفع الملفات، الدردشة المباشرة (Socket.io)
lib/                 قاعدة بيانات JSON، تسجيل الدخول، المحتوى الافتراضي
public/index.html    صفحة الموقع
public/js/           واجهة الموقع، المجسم ثلاثي الأبعاد، الدردشة
public/admin/        لوحة التحكم
test/                اختبارات (npm test)
```

## الأمان

- إجبار تغيير كلمة المرور الافتراضية قبل الوصول لأي بيانات، وحد أدنى 8 أحرف.
- حماية من تخمين كلمات المرور (حد للمحاولات لكل عنوان ولكل حساب)، وعدم كشف أسماء المستخدمين.
- إيصالات الدفع وصور الدردشة خاصة، وتُعرض فقط عبر روابط موقّعة تنتهي صلاحيتها.
- فحص محتوى الملفات المرفوعة فعليًا (وليس الامتداد فقط)، ومنع ملفات SVG/HTML.
- ترويسات أمان كاملة: Content-Security-Policy، منع التضمين في مواقع أخرى، HSTS عند HTTPS.
- تنقية كل المدخلات ومنع الروابط الخطرة (`javascript:`)، وعدم إظهار تفاصيل الأخطاء الداخلية.
- ملفات البيانات محمية بصلاحيات (600)، واختبارات أمان تلقائية ضمن `npm test`.

**مسؤوليتك عند النشر:** استخدم HTTPS دائمًا، كلمة مرور قوية، وخذ نسخة احتياطية من `data/` و`uploads/`.
